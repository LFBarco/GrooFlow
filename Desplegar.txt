Cómo funciona ahora (simple)
Trabajo en pruebas: rama dev
Paso a producción: fusionar dev -> main y desplegar prod
Comandos que usarás
Probar cambios (preview)
git checkout dev
# haces cambios
git add .
git commit -m "cambios en pruebas"
git push
npm run deploy:preview
Pasar a producción
git checkout main
git pull
git merge dev
git push
npm run deploy:prod
Cómo pedírmelo a mí (automático)
Puedes decirme literalmente:

“Trabajemos en pruebas” -> hago cambios en dev y despliego preview.
“Pasa esto a producción” -> fusiono dev a main y despliego prod.
“Solo sube preview” -> ejecuto npm run deploy:preview.
“Despliega producción” -> ejecuto npm run deploy:prod.
Si quieres, en el siguiente paso te dejo también un alias más corto tipo npm run qa y npm run prod para que sea aún más rápido.
